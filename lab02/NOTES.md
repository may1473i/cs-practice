Git - это система контроля версий. А GitHub - это сайт, где можно хранить свои репозитории. 

git status показывает в каком состоянии находится рабочая директория

git diff - изменения файлов, которые не были добавлены в staged (без индекса)

git diff --staged показывает изменения файлов, которые были проиндексированы
